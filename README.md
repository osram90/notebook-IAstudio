# Notebook Studio

Entorno de notebooks Python y R con asistente de IA, para escritorio Windows.

- **Kernel real:** Python y R, con kernels independientes de Jupyter.
- **Asistente de IA:** en la nube (con tus propias claves) o local con Ollama.
- **Publicación:** exporta o publica el notebook como página HTML para alumnos.
- **Investigación:** búsqueda en Crossref, OpenAlex, PubMed, arXiv y otros, con verificación de DOI.

## Instalación

1. Descarga `NotebookStudio-Setup-1.0.0.exe` desde [Releases](https://github.com/osram90/notebook-IAstudio/releases/latest).
2. Ejecútalo. La app trae su propio Python; no necesitas instalar nada más.
3. Opcionales: Ollama (IA local) y R 4.5 con IRkernel.

## Contenido de este repositorio

- `index.html`: página de presentación con un ejemplo que se ejecuta en el navegador (Pyodide).
- `ejemplos/`: notebook de ejemplo (`.ipynb`) y su versión publicada en HTML.
- `img/`: capturas.
